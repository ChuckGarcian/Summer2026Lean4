## 1 [Lemma 5.12]

Suppose $p \in R[\set{x_k}]$, $k\in [n]$ and suppose that $p$ approximates parity. That is,

$$\forall x \in \set{-1,1}\colon \mid p(\vec{x}) - (-1)^t | \leq 2\epsilon$$

then, we claim that there exists a single variate polynomial $q(t)$ s.t q is the average of $p(x)$ over hamming weight $t$ of $x\in \set{-1,1}$.

$$q(t) = \frac{1}{n!}\sum_{\vec{x}} p(\vec{x})$$

**Proof:** Let $p$ be a multivariate polynomial with the propert that

$$\forall x \in \set{-1,1}\colon \mid p(\vec{x}) - (-1)^t | \leq 2\epsilon$$

We need to show the symmetrization of $p$, q, also has this property.

$$\frac{1}{n!}\left[p(\vec{x_1}) + \ldots + p(\vec{x_n})\right] = q(t)$$

So,

$$\forall x \in \set{-1,1}\colon \mid p(\vec{x}) - (-1)^t | \leq 2\epsilon$$

$$\iff$$

$$\forall x \in \set{-1,1}\colon |(-1)^t| \mid p(\vec{x}) - (-1)^t | \leq |(-1)^t| 2\epsilon$$

$$\iff$$

$$\forall x \in \set{-1,1}\colon \mid (-1)^t p(\vec{x}) - |(-1)^{2t}| \leq 1* 2\epsilon$$

$$\iff$$

$$\forall x \in \set{-1,1}\colon \mid (-1)^t p(\vec{x}) - 1\mid \leq 2\epsilon$$

$$\iff$$

$$\forall x \in \set{-1,1}\colon -2\epsilon\leq (-1)^t p(\vec{x}) - 1 \leq 2\epsilon$$

$$\iff$$

$$\forall x \in \set{-1,1}\colon -2\epsilon + 1\leq (-1)^t p(\vec{x})\leq 2\epsilon + 1$$

So,

$$\forall x \in \set{-1,1}\colon -2\epsilon + 1\leq (-1)^t p(\vec{x})$$

By convexity

$$\forall x \in \set{-1,1}\colon \left(-2\epsilon + 1\right)+\ldots + \left(-2\epsilon + 1\right)\leq (-1)^t p(\vec{x_1}) + \ldots + (-1)^t p(\vec{x_n})$$

$$\forall x \in \set{-1,1}\colon (n!)\left(-2\epsilon + 1\right)\leq (-1)^t \left(p(\vec{x_1}) + \ldots +p(\vec{x_n})\right)$$

Now, by definition $q(t) = \frac{\left(p(\vec{x_1}) + \ldots +p(\vec{x_n})\right)}{n!}$

$$\forall x \in \set{-1,1}\colon (n!)\left(-2\epsilon + 1\right)\leq (-1)^t (n!)q(t)$$

$$\forall x \in \set{-1,1}\colon (n!)\left(-2\epsilon + 1\right)\leq (-1)^t (n!)q(t)$$

$$\forall x \in \set{-1,1}\colon \left(-2\epsilon + 1\right)\leq (-1)^tq(t)$$
