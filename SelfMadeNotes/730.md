## 1: Example showing that a symmetric polynomial has a unique expansion in the elementary symmetric basis

**Example 1:**  Express symmetric, multilinear $p \in R[x_1, \ldots, x_n]$ in the elementary symmetric basis.

Let $p^s$ be given as

$$p (x,y,z) = x + y + z - xyz$$

Observe $p^s$ is symmetric since any permutation of its variables gives the same polynomial.

Then let $\left\{p_0, p_1, p_2\right\}$ be the set of elementary symmetric polynomials in 3 variables. That is

$$p_0(x,y,z) = 1$$
$$p_1(x,y,z) = x + y + z$$
$$p_2 (x,y,z) = xy + yz + zx$$
$$p_3 (x,y,z) = xyz$$

So, we can write

$$p^{s} = c_0p_0 + c_1p_1 + c_2p_2 + c_3 p_3$$ 

For some real constants $c_0, c_1, c_2, c_3$. In particular, take $c_0 = 0$, $c_1 = 1$, $c_3 = -1$. Then,

$$p^{s}(x,y,z) = p_1(x,y,z) - p_3(x,y,z)$$

$$\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad \blacksquare$$

## 2: Showing that the polynomial from Example 1, when restricted to the Boolean domain, can be expressed as a univariate polynomial

**Example 2:** Write $p^s$ in terms of a univariate polynomial.

From the previous example, $p^{s}(x,y,z) = p_1(x,y,z) - p_3(x,y,z)$. 

We now want to show that we can write $p^s$ as a univariate polynomial in $p_1$. That is, we want to show there exists univariate polynomial $q(t)$ such that 

$$p(x,y,z) = q(p_0(x,y,z))$$

In particular, observe that 

$$p_1^2 = (x+y+z)^2 = 2xy + 2yz + 2xz + x + y + z = 2p_2 + p_1$$

$$p_2 = \frac{1}{2}p_1^2 - \frac{1}{2}p_1$$

Moreover, $p_3$ can be written as 

$$3p_3 = p_1p_2 - 3p_2= (x + y + z) (xy + yz + zx) - 3p_2$$

$$p_3 = \frac{1}{3}p_1 p_2 - p_2 
= \frac{1}{3}p_1 \left(\frac{1}{2}p_1^2 - \frac{1}{2}p_1\right) - \left( \frac{1}{2}p_1^2 - \frac{1}{2}p_1\right)$$

Where we use multilinearity of $p^s$. We can then simplify,

$$p_3 = \frac{1}{6}p_1^3 - \frac{1}{6}p_1^2 -\frac{1}{2}p_1^2 + \frac{1}{2}p_1$$

$$p_3 = \frac{1}{6}p_1^3 - \frac{8}{12} p_1^2 + \frac{1}{2}p_1$$

$$p_3 = \frac{1}{6}p_1^3 - \frac{2}{3} p_1^2 + \frac{1}{2}p_1$$

Indeed, 

$$p^s (x,y,z) = p_1 - p_3 =  \frac{1}{2}p_1^2 - \frac{1}{2}p_1 - \frac{1}{6}p_1^3 + \frac{2}{3} p_1^2 - \frac{1}{2}p_1$$

Whence, take $q(t) = \frac{1}{2}t^2 - \frac{1}{2}t - \frac{1}{6}t^3 + \frac{2}{3} t^2 - \frac{1}{2}t$ Where, for sake of sanity, we forgo simplification. Then indeed $p^s(x,y,z)$ is equal to a univariate polynomial in $x + y + z = p_0$. Namely, 

$$p ^ s(x,y,z) = q (x + y + z)$$

$$\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad \blacksquare$$

## 3: Example - General 2 variables symm, multi into univariate

**Example 3:** Let $p (x,y)$ be a real polynomial that is symmetric and multilinear that is, $p(x, y) = p(y, x)$ for all $x, y$ and $p(x, y)$. Then there exists a real polynomial $q(t )$ such that $p (x, y) = q (x + y)$.

**Proof:** Let $p(x,y)$ be a symmetric polynomial. Then, by the fundamental theorem of symmetric polynomials every symmetric polynomial in $n$ variables can be expressed uniquely as a polynomial in elementary symmetric polynomials in $n$ variables.

In two variables the elementary symmetric polynomials are $1$, $x+y$ and $xy$. This means that

$$p (x,y) = c_0 + c_1(x+y) + c_2 xy$$

$$p (x,y) = c_0 + c_1p_1 + c_2 p_2$$

Observe,

$$p_1^2 = (x+y)^2 = x^2 + y^2 + 2xy = p_1 +2 p_2$$

$$p_1^2 = 2p_2 + p_1$$

$$p_1^2 - p_1 = 2p_2$$

$$\frac{1}{2}p_1^2 - \frac{1}{2}p_1 = p_2$$

So

$$p (x,y) = c_0 + c_1p_1 + c_2 \frac{1}{2}p_1^2 - c_2\frac{1}{2}p_1$$

$$p (x,y) = c_0 + c_1p_1 - c_2\frac{1}{2}p_1 + c_2 \frac{1}{2}p_1^2$$

$$p (x,y) = c_0 + \left(c_1 - c_2\frac{1}{2}\right)p_1 + c_2 \frac{1}{2}p_1^2$$

Take 

$$\boxed{q(t) = c_0 + \left(c_1 - c_2\frac{1}{2}\right)t + c_2 \frac{1}{2}t^2}$$ 

This gives the claim $\blacksquare$

## 5: Main theorem - A symmtric univariate polynomial can be written as a univariate

We can generalize the previous examples into the following theorem

**Theorem 1:** Let $p \in R[x_1,\dots, x_n]$ be a symmetric, polynomial. We claim that there is a univariate polynomial $q\in R[t]$ such that

$$\forall x\in \{0,1\}^n\colon \quad p(x_1, \ldots, x_n) = q(x_1 + \ldots + x_n)$$

**Proof:**

Let $p \in R[x_1,\dots, x_n]$ be a symmetric, polynomial. Then $p$ can be expressed as a linear combination of the symmetric elementary polynomial basis

$$p(x_1, \ldots, x_n) = \sum_j^{deg(p)} c_jE_j(x_1, \ldots, x_n)$$

Where $c_k's$ are the constants and each $E_j$ is an elementary symmetric polynomial in $n$ variables. We will that for each $E_j$ there is a univariate polynomial $q_j$ such that

$$\forall x \in \{0,1\}^n\colon\quad E_j(x_1, \ldots, x_n) = q_j (x_1 + \ldots + x_n)\quad\text{and}\quad q (t) = \sum^{j}_{k=1} d_k t^k$$



We will use induction to show the claim. In particular, let $S(k)$ denote the following statement.

$$S(j)\colon E_j(x_1,\ldots, x_n) = \sum^{j}_{k=1} d_k E_1^k(x_1,\ldots, x_n)$$

**Base Case:** $S(0)$

We need to show the following is true

$$S(1)\colon E_1(x_1,\ldots, x_n) = \sum^{1}_{k=1} d_k q_k \left(x_1 +\ldots + x_n\right), \space\space\space q \in R\left[t\right]$$

Trivially take $q(t) = t$, then $E_1 = q(E_1) = q \left(x_1 + \ldots + x_n\right)$

This gives the claim.

**Inductive Case:** Suppose the $S(j-1)$ is true for some $j\geq2$. That is, assume $E_{j-1}$ is a degree $j-1$ elementary polynomial, 
such that 

$$E_{j-1}(x_1,\ldots, x_n) = \sum^{j-1}_{k=1} d_k E_1^k(x_1,\ldots, x_n)$$

Then we want to show that $S(j)$ is true. That is we want to show 

$$E_{j}(x_1,\ldots, x_n) = \sum^{j}_{k=1} d_k E_1^k(x_1,\ldots, x_n)$$

Consider the product $E_1^j$. Then note that the product of two symmetric polynomials is itself symmetric. So we can write

$$E_1^j = \sum^j_k d_kE_k$$

Split off the jth term

$$E_1^j =  d_jE_j + \sum^{j-1}_k d_kE_j$$

Invoke the inductive hypothesis

$$E_1^j =  d_jE_j + \sum^{j-1}_k d_k q(E_1)$$

Solve for $E_j$

$$E_j = \frac{E_1^j + \sum^{j-1}_k d_k q(E_1)}{d_j}$$

$$E_j = \frac{1}{d_j}\left[E_1^j + \sum^{j-1}_k d_k q_k\left(E_1\right)\right]$$

Take 

$$q_j(t) = \frac{1}{d_j}\left[t^j + \sum^{j-1}_k d_k q_k\left(t\right)\right]$$

This gives the claim. $\blacksquare$
