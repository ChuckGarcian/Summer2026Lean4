## 1 composing polynomials

How can I evaluate a polynomial to get another polynomial? As an example, let $p(x) = X^2 + 2$ and $q(Y)=Y+1$ be polynomials; how can one get $p(q(Y))=(Y+1)^2 + 2$?

Answer: Using comp

      example :  comp (X^2 : R[X]) (X+1: R[X]) = ((X+1)^2 :R[X] ) := by simp
