## 1

**Claim:** 

Let $p^{symm} \in R[x_1, \ldots, x_n]$. We claim 

$$\exists q \in R[x]\colon q(x_1 + \ldots + x_n) = p^{symm} (x_1, \ldots, x_n)$$

**Proof:**

$p$ is a symmetric polynomial. This means that $p$ can be expressed in terms of the elementary symmetric basis

$$p_1 = x_1 + \ldots + x_n$$
$$p_2 = x_1x_2 + \ldots + x_{n-1}x_n$$

Rewriting, we have 

$$p = \sum_k^{deg (p)}a_k p_k$$

**Base Case: n = 0**

This case is trivial as $p$ is equal to the constant polynomial.

**Base Case n=1:**

$$p(x) = a_1 + a_2 x$$

Then take 

$$q(t) = a_1 + a_2 x|$$

**Base Case: n=2:**

$$p (x, y) = a_11 + a_2 p_2 + a_3p_3 + a_4 p_4$$

$$p (x, y) = a_1 + a_2 (x + y) + a_3 xy$$


------

Let $p$ be a symmetric polynomial. Then $p$ can be written as

$$p = \sum_j c_j p_j$$


If $p$ is symmetric then $p(x) = \sum t^k$


**Inductive Case:** Assume symmetric polynomial of degree k - 1, $p_{k-1}$, can be expressed as a real polynomial of degree $k-1$ in $x_1+\ldots+x_n$. We want to show that $p_k$ can be expressed as a degree $k$ polynomial in $t = x_1 + \ldots + x_n$.

Observe that 

$$t^k = (x_1+\ldots + x_n)^k$$

$$t^k= \sum_{\text{Distinct: } s_1,\ldots, s_k\in [n]} x_{s_1}\ldots x_{s_k} + \sum _{\text{Not distinct: } s_1,\ldots, s_k\in [n]}x_{s_1}\ldots x_{s_n}$$

Observe, The left term is definitionally equal to $p_k$. We can factor out $s_1$

$$t^k = p_k + \sum _{s_1}x_{s_1}\sum_{s_2,\ldots s_k} x_{s_2}\ldots x_{s_n}$$

The remaining sum is a sum over $s_2, \ldots, s_k \in [n]$ that may or may not be distinct which is equalevent to $(x_1 + \ldots + x_n)^{k-1} = t^{k-1}$

$$t^k = p_k + \sum _{s_1}x_{s_1}t^{k-1}$$

$$t^k = p_k + t^{k-1}\sum _{s_1}x_{s_1}$$

Use the definitoin of $p_1$

$$t^k = p_k + t^{k-1}p_1$$

We can rewrite to get

$$p_k = t^k - t^{k-1}p_1$$

By the inductive hypothesis, $t^{k-1}$ is a real valued polynomial in $t$
